About PhishGuard

Machine Learning Based Phishing Website Detection and Risk Analysis System

Project Overview

PhishGuard is a machine-learning-based project designed to classify URLs as potentially phishing or legitimate using extracted URL features.

It combines predictions from three machine learning algorithms to generate an overall classification and a simple risk level.

Project Objectives

URL Analysis

Analyze URL characteristics using extracted features.

ML Prediction

Use three trained ML models to classify URL text.

Risk Analysis

Display combined prediction and save scan history.

How PhishGuard Works

  1. The user enters a URL as text.
  2. The system extracts numerical features from the URL.
  3. Three trained machine learning models make predictions.
  4. The system combines the predictions using majority voting.
  5. The result and risk category are displayed and saved in scan history.
