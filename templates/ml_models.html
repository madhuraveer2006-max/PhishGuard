Model Testing Methodology

  • The dataset is divided into 80% training data and 20% testing data.
  • Stratified splitting preserves the class proportions in both sets.
  • The same held-out test set is used to evaluate all three algorithms.
  • Metrics and confusion matrices are calculated from actual test predictions.
  • These results describe the supplied dataset and do not guarantee detection of every new phishing URL.

Understanding Evaluation Metrics

Accuracy: Overall proportion of correct predictions.

Balanced Accuracy: Average recall across the classes.

Precision: Proportion of predicted phishing cases that were actually phishing.

Recall: Proportion of actual phishing cases correctly identified.

F1-Score: Harmonic mean of precision and recall.

Dataset Limitation

The dataset contains far more phishing examples than legitimate examples. Accuracy alone may therefore be misleading. Balanced accuracy and the confusion matrix should also be considered. The current scanner uses URL-text features only; it does not visit the website, inspect page content, or verify the website owner. Predictions are not a guarantee of safety.

Future Scope

  • Evaluate the models on a newer, independent dataset containing unseen URLs.
  • Increase and improve the variety of legitimate URL examples.
  • Explore additional URL and domain features and compare their contribution.
  • Monitor model performance as phishing URL patterns change over time.
